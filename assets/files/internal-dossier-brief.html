2 Two ChatGPT models—what they are & when to use them

Model How it’s trained / strengths Use it for
GPT-4o (default tab) Multimodal, creative, fast; excels at narrative drafting, idea generation. Brainstorming headings, rewriting prose, summarising articles.
o3 (Reasoner) Optimised for step-by-step logic, numerical reasoning, and tighter chain-of-thought. Calculations, ratio checks, code execution, catching GPT-4o’s math errors.

Workflow suggestion: draft with GPT-4o → verify numbers & produce charts in o3.

Switch models via the dropdown at the top of the Project chat window.

3 Set up your Project Folder

  1. ChatGPT sidebar → Projects → New Project
    Name it BUSMGT450_W2_[Company].

  2. Uploads required

    • Case file (Word / PDF)

    • 5 outside documents, INCLUDING ≥ 2 numeric sources (banker reports, 10-K PDF, Statista CSV).

  3. Turn OFF “Chat History & Training” (Settings → Data Controls).

4 Gather 3-year financials from Capital IQ

  1. Visit
    https://libproxy.boisestate.edu/login?url=https://na.capitaliq.com/ip/BOSTU

  2. Log in with Boise State credentials.

  3. Search your company → Financials / Key Stats → Export at least 3 years of revenue, operating income, ROIC, and any other ratios you want.

  4. Save as CSV or Excel and upload the file to your Project.

Tip: Smaller CSVs (only the fields you need) run faster inside ChatGPT.

7 Quick Tips

  • Start with GPT-4o to outline resource buckets, then switch to o3 for ROIC math.

  • Ask o3 to “show every calculation step”—then run the same math “in canvas” to double-check.

  • Embed at least one line-chart or bar-chart of a 3-year metric in your memo; reference it in the text.

  • Use Value-Chain to explain cost drivers; VRIO to judge uniqueness & imitability.
