2 Project set-up in ChatGPT Pro

Step What to do Why it matters
a. Create Project Sidebar ➜ Projects ➜ New Project ➜ name it BUSMGT450_W3_[Company]. Keeps every file, prompt, and tool run in one sandbox.
b. Upload knowledge base Drag the case file and at least five outside sources (two must contain global or tech diffusion data) into the Project. Gives GPT a private “mini-library” it can cite—no hallucinated URLs.
c. Write a System Prompt Click Settings inside the Project ➜ System prompt field. Enter one paragraph that:• States this is Week 3 Global-Tech assignment• Tells GPT to write in clear, concise business English (APA citations)• Reminds GPT that all answers must reference the uploaded knowledge base and saved Deep Research excerpts• Lists core frameworks: Porter’s Diamond, Entry Modes, Crossing the Chasm, Disruptive Innovation, Diffusion curve. A system prompt sets the “rules of engagement.” It stays constant across sessions, so you don’t have to repeat instructions and GPT’s style stays consistent.
d. Model switching Use GPT-4o for drafting prose. Switch to o3 (Reasoner) for calculations or logic checks. o3 is tuned for step-by-step reasoning.
e. Tool access Confirm the right-side icons appear:🔍 Deep Research 🎨 Image Gen 🎬 Sora These are the three skills you will practice this week.
f. Privacy Settings ➜ Data Controls ➜ Chat History & Training OFF. Keeps course work out of future model training.

6 FAQ (share with students)

  1. What’s a system prompt?
    A permanent set of instructions the model reads before every chat message. Think of it as a course style guide plus guard-rails.

  2. Do I paste my system prompt into the memo?
    Yes.

  3. How long should the Sora video be?
    Around 10 seconds. Short is fine as long as it communicates one clear idea.

  4. Can I reuse the Week 1/2 template?
    There is no template this week—you design headings, visuals, and narrative flow yourself.
