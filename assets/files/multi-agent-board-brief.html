PHASE 1 — Project & System Prompt (≈10 min)

Action Exact clicks & text Why
1. Create project Sidebar ➜ Projects ➜ New Project → name BUSMGT450_W5_[Company] Keeps everything in one sandbox.
2. Upload files Drag in the case file + 5 outside sources (at least 2 on governance/ethics). Gives GPT a mini-library to cite.
3. Add system prompt Project header ➜ Settings ➜ System Prompt field → paste & edit the sample below. Sets permanent rules for every chat.

Sample system prompt (edit bracketed parts)

Roles: CEO, CFO, General Counsel, Independent Director, Board Ethicist.
Each role will speak once (≤150 words) and tag stance at top: [YES] [NO] [MAYBE].
Style: concise boardroom English, APA in-text citations to knowledge-base docs only.
Frameworks to reference when relevant: Better-Off Test, Ownership Test, Parenting Advantage, stakeholder theory, agency theory.
Finish by waiting for the user's next instruction.

PHASE 2 — Collect Agent Opinions (≈20 min)

  1. Stay inside the same Project chat (GPT-4o is fine).

  2. For each role, paste the template below, editing the bracketed text:

##agent role=CEO
Prompt: Given the uploaded files, should the board approve [the GE break-up into three companies] today? Provide one strategic reason, one risk, stance tag, ≤150 words.

##agent role=CFO
Prompt: Same question. Base answer on financial & valuation data.

##agent role=General Counsel
Prompt: Identify any regulatory or fiduciary concerns.

##agent role=Independent Director
Prompt: Evaluate from minority shareholder & reputation angle.

##agent role=Board Ethicist
Prompt: Assess broader stakeholder impacts & ESG obligations.

  1. After all five replies paste:

Switch to o3 (Reasoner), then:  
"Act as neutral board secretary. Summarise where the five roles agree / partly agree / disagree. List any data still needed."

Copy these outputs into a text file—you’ll need them for the log.

PHASE 3 — Create the Consensus Matrix (≈5 min)

Quick method
In ChatGPT: “Create a 5×3 table: rows = CEO, CFO, GC, ID, Ethicist; columns = YES, NO, MAYBE. Mark each cell with ✓ based on stance tags above.”
Copy the table into PowerPoint/Word → save as ConsensusMatrix.png (right-click → Save as Picture).

PHASE 4 — Write the Board Brief (≈60 min)

Section Guideline
A. Issue & Context (≤150 w) What strategic scope choice is on the table?
B. Agent Positions (≈250 w) Summarise each role’s key point using APA citations & AgentLog references.
C. Analysis (≈400 w) Apply ≥ 2 frameworks (e.g., Better-Off Test + shareholder supremacy + stakeholder theory). Show why some arguments carry more weight.
D. Recommendation (≈150 w) One clear decision + at least two risk-mitigation steps.
E. AI Reflection (≤150 w) 1–2 things multi-agent GPT added; 1–2 limits you still handled manually.

Embed ConsensusMatrix.png where it best supports the story.
Total length goal: 1 000–1 300 words.

Quick FAQ

  • Where do I type ##agent role=?
    Just paste it at the start of each new message in the same Project chat.

  • Word limit strict?
    ±10 % is fine; clarity beats length.

  • Can I add extra roles?
    Yes, but keep each to ≤150 words.

  • Trouble exporting the matrix?
    A plain screenshot (PNG) is acceptable.
