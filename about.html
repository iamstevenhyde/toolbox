About

A catalog, and an argument about how teaching gets made.

The Toolbox is a working collection of AI activities, bots, simulations, and live cases, all run with real students in strategy courses at Boise State. It does two jobs. It hands faculty something that already works in a classroom, and it shows what course materials can look like when they are built and shared in the open.

Most advice about AI in the classroom stops at the idea. This stops at the other end.

For faculty

Every item on the Bench ships with the actual prompt, a run of show, and the debrief questions, so you can read it tonight and run it tomorrow. Take what is useful. Change what is not. Nothing here asks for permission or a license. The point is adoption, not admiration.

The model

These courses do not run on one bound textbook. They run on NotebookLMs of primary sources, on cases built from things that actually happened, and on activities like these. The Toolbox is what that looks like when it is published openly. One instructor's materials, free to copy, with the reasoning left in so you can adapt them rather than only reuse them.

Where it goes

The larger bet is that this is how teaching material gets made next. Not a publisher's sealed edition every seven years, but living catalogs that instructors grow, borrow from, and hand back. If something works in your own room, the Submit page is open.
